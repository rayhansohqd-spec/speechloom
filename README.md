## 🎯 Core Features

### 🎵 Waveform Encoding
speechloom converts raw audio into digital signals that computers can process. This is like translating sound into a language your PC understands.

### 🔄 Causal Decoding
The system processes speech in real-time order, similar to how you listen to someone speak - word by word, without jumping ahead.

### 🔢 Codec Tokens
Audio gets broken down into small, manageable chunks called "tokens." Think of these as LEGO blocks that can be reassembled into complete sentences.

### ⚖️ Joint Losses
The software uses multiple learning signals simultaneously to improve accuracy. It's like learning a language by reading, listening, and speaking all at once.

### 📡 Streaming Support
Process audio live as it comes in, perfect for real-time applications like live captioning or voice assistants.
